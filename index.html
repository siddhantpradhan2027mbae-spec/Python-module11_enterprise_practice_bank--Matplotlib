Install once: pip install matplotlib seaborn plotly pandas

Build a chart in four moves

  1. What is the question: a trend, a comparison or a share?
  2. Pick a line, bar or pie chart.
  3. Draw it, then add title, labels and legend.
  4. Save first, show last.

Seaborn and Plotly

  • Put the data in a DataFrame.
  • Name the columns for x, y and colour.
  • Seaborn makes pictures for reports.
  • Plotly makes interactive charts for dashboards.

Check a chart without looking

  1. Print the title and the labels.
  2. Count the bars, lines or slices.
  3. Check that saved files exist.
  4. Compare with the expected chart.
Stuck? Print what the chart holds, for example print(ax.get_title()) or print(len(ax.patches)). If no window opens on your laptop, replace plt.show() with plt.savefig("x.png") and open the file.
